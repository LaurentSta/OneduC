# Code de conduite — Communauté Oneduc

## Engagement

La communauté Oneduc s'engage à maintenir un espace de contribution professionnel, respectueux et centré sur l'amélioration d'un outil d'inclusion numérique.

Ce code s'applique aux échanges publics et privés liés au projet : Issues, Pull Requests, Discussions, documentation, événements, courriels et espaces communautaires.

## Comportements attendus

Les comportements attendus sont les suivants :

- formuler les désaccords avec respect ;
- argumenter les choix techniques et pédagogiques ;
- accueillir les contributions débutantes avec exigence mais sans mépris ;
- signaler les problèmes de sécurité de manière responsable ;
- respecter la confidentialité des données et situations de formation ;
- tenir compte des enjeux d'accessibilité, d'inclusion numérique et de RGPD ;
- éviter les attaques personnelles, insinuations ou propos discriminatoires.

## Comportements non acceptés

Ne sont pas acceptés :

- propos discriminatoires, humiliants ou harcelants ;
- attaques personnelles ;
- publication de données personnelles ;
- publication de secrets, failles exploitables ou informations sensibles ;
- pression insistante sur les mainteneurs ;
- dénigrement des utilisateurs débutants ou des publics éloignés du numérique ;
- contributions volontairement malveillantes ;
- usages commerciaux trompeurs laissant croire à un soutien officiel de l'Association Oneduc sans accord explicite.

## Application

Les mainteneurs peuvent prendre les mesures suivantes :

1. rappel à la règle ;
2. demande de reformulation ;
3. fermeture d'une discussion ;
4. refus ou annulation d'une contribution ;
5. restriction temporaire ou définitive de participation ;
6. signalement à la plateforme concernée si nécessaire.

## Signalement

Les comportements problématiques peuvent être signalés à : contact@oneduc.fr

Le signalement doit contenir, si possible :

- le contexte ;
- les liens ou captures utiles ;
- les personnes concernées ;
- l'effet produit ;
- la mesure souhaitée.

Les signalements seront traités avec discrétion.

## Référence

Ce code s'inspire des pratiques courantes des communautés libres et du Contributor Covenant 2.1, tout en étant adapté au contexte associatif, pédagogique et francophone d'Oneduc.
