# Acceder au module 2 - Formation de groupe

Date : 2026-06-05  
Public concerne : formateurs Oneduc  
Module : `Module 2 - Mettre en place un environnement de formation`

## Objectif

Ce document explique comment acceder au module 2 une fois connecte a Oneduc.

Le module 2 accompagne le formateur dans la mise en place d un environnement de formation : preparation des informations, creation d un groupe, organisation des modules, ajustement du groupe et securisation des acces.

## Conditions d acces

Avant de commencer, verifier que :

- le compte utilise est un compte formateur ;
- l utilisateur est connecte a Oneduc ;
- le compte est rattache a une association active ;
- le menu formateur est visible apres connexion.

Si le menu formateur n apparait pas, le compte utilise n a probablement pas le role formateur ou n est pas correctement rattache.

## Acces depuis l interface

1. Se connecter a Oneduc avec son compte formateur.

2. Arriver sur le tableau de bord formateur.

3. Dans la barre laterale gauche, descendre en bas du menu.

4. Cliquer sur `Formation formateur`.

5. La page `Formation a l utilisation d Oneduc` s ouvre.

6. Dans la liste des modules, reperer `Module 2`.

7. Cliquer sur le bouton `Entrer dans le module`.

8. La page d introduction du module 2 s ouvre. Elle presente les reperes de navigation avant le demarrage.

9. Cliquer sur le bouton de demarrage ou suivre l action proposee pour commencer le module.

## Acces direct

Si le formateur est deja connecte, il peut acceder directement au module 2 avec l URL suivante :

```text
/formateur/parcours-formateur/modules/organiser-ses-parcours
```

Pour ouvrir directement l introduction du module 2 :

```text
/formateur/parcours-formateur/modules/organiser-ses-parcours/introduction
```

Ces liens fonctionnent uniquement pour un utilisateur connecte avec le role formateur.

## Contenu du module 2

Le module 2 est organise en trois chapitres :

| Chapitre | Objectif |
| --- | --- |
| Preparer avant de creer | Verifier que les informations indispensables sont pretes avant d ouvrir un groupe. |
| Creer et organiser | Creer un groupe puis construire un parcours coherent avec les modules attendus. |
| Ajuster et securiser | Ajuster un groupe existant, securiser les acces et traiter les cas particuliers. |

Les principales lecons sont :

- `Identifier les elements essentiels` ;
- `Preparer les informations utiles` ;
- `Creer un groupe de formation` ;
- `Creer un parcours` ;
- `Ajuster le groupe` ;
- `Traiter les cas particuliers` ;
- `Bilan du module 2 et ouverture vers le module 3`.

## En cas de blocage

Si le module 2 n est pas visible :

- verifier que l utilisateur est bien connecte avec un compte formateur ;
- revenir au tableau de bord formateur puis rouvrir `Formation formateur` ;
- essayer l URL directe du module ;
- demander a un administrateur de verifier le role et le rattachement a l association.

Si l utilisateur est redirige vers une page de connexion ou une page non autorisee, cela signifie que la session a expire ou que les droits du compte ne permettent pas d acceder au parcours formateur.
