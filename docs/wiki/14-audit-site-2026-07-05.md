## Crawl HTTP public

23 routes GET publiques sans paramètres ont été testées.

| Statut | Nombre | Détail |
|--------|--------|--------|
| HTTP 200 | 22 | Accueil, catalogue, pages légales, connexion, inscription formateur, contact, nuage de mots public, accès stagiaire, etc. |
| HTTP 500 | 1 | `/inscription` |

Erreur relevée sur `/inscription` :

```text
Call to undefined method App\Http\Controllers\UserController::Register()
```

La route est déclarée dans `routes/web.php`, mais `UserController::Register()` n'existe plus. La page `/inscription-formateur` fonctionne et semble être l'entrée publique réellement utilisée depuis l'accueil.

## Validations techniques

| Commande | Résultat |
|----------|----------|
| `php artisan test` | 103 tests passés, 1 échec, 505 assertions |
| `npm run build` | Réussi, avec avertissements Vite sur directives `"use client"` et chunks supérieurs à 500 kB |
| `php artisan migrate:status` | 5 migrations post-baseline marquées `Ran` |
| `php artisan about --only=environment,cache,drivers` | Laravel 11.42.0, PHP 8.3.6, DB MySQL, queue/session/cache database |

Échec de test identifié :

```text
Tests\Feature\Formateur\ModuleBuilderTest
Invalid expectation value type. Expected [string].
tests/Feature/Formateur/ModuleBuilderTest.php:59
```

Le test attend un champ JSON `path` après upload d'image dans le builder formateur. Le contrôleur `ModuleBuilderController::uploadImage()` retourne actuellement `media_id` et `url` via Spatie Media Library. Il faut clarifier le contrat attendu par l'éditeur de blocs : stockage par chemin historique ou référence media library.
