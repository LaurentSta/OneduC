# Parcours formateur Oneduc

Date : 2026-05-08  
URL : `/formateur/parcours-formateur`

## Utilite du parcours

Le parcours formateur sert a accompagner les formateurs dans la prise en main de la plateforme Oneduc.

Il a trois roles principaux :

- donner des reperes simples dans l espace formateur ;
- guider la mise en place d un premier environnement de formation ;
- preparer l integration progressive des contenus de lecon, activites et bilans.

Ce parcours sert de support de demonstration de la logique pedagogique d Oneduc : il permet de montrer une structuration claire sans surcharger l interface avec trop de texte. Les objectifs pedagogiques et operationnels restent presents dans la structure, mais l affichage web privilegie des titres courts, lisibles et faciles a parcourir.

## Principe de structuration

La structure suit la logique pedagogique suivante :

- module : objectif specifique ;
- chapitre : objectif pedagogique ;
- lecon : objectif operationnel ;
- activite : exercice ou interaction a creer progressivement ;
- bilan : moment de synthese du module.

Les contenus sont codes en dur dans l application, car le parcours doit rester integre directement au site. Les pages de lecon sont volontairement laissees comme espaces vides afin de pouvoir y integrer les contenus de lecon au fur et a mesure.

## Page d introduction de module

Une page d introduction est ajoutee avant l entree dans les chapitres d un module.

Son objectif est d expliquer rapidement l usage des principaux boutons et reperes :

- derouler un chapitre avec la fleche orange ;
- ouvrir une lecon ;
- suivre un contenu de lecon dans l espace de lecon ;
- lancer une activite lorsqu elle est disponible ;
- revenir au plan via la sidebar ;
- avancer avec les boutons de navigation.

Cette page evite d entrer trop vite dans les contenus. Elle installe les habitudes de navigation avant le debut du module.

## Choix d interface

L interface a ete volontairement allegee :

- les titres visibles sont courts ;
- les numeros comme `1.1` ou `1.1.1` ne sont plus affiches ;
- les mentions longues sont placees au survol quand elles sont utiles ;
- les pages de lecon affichent un espace vide pour recevoir le futur contenu de lecon ;
- les activites sont signalees comme disponibles ou a creer ;
- la fleche de deroulement des chapitres est mise en evidence.

Ce choix permet d avoir une interface plus adaptee au web, plus lisible et plus facile a presenter.
